## Gambaran Proyek

Website portofolio rekayasa perangkat lunak yang dirancang dengan standar arsitektur modern, mengutamakan performa pemuatan super cepat (*zero-JS by default*), modularitas komponen, dan kemudahan kurasi konten melalui Git-based CMS.

### Arsitektur & Teknologi

1. **Astro Static Site Generation (SSG)**
   * Menghasilkan HTML statis murni dengan *zero client-side JavaScript overhead* pada section konten statis, memaksimalkan skor Core Web Vitals (LCP, FID/INP, CLS).
2. **React Islands Architecture**
   * Mengisolasi interaktivitas kompleks (seperti form dinamis, integrasi 3D Three.js, dan visualisasi telemetri) dalam pulau-pulau komponen yang terhidrasi secara selektif (*partial hydration*).
3. **Design System & Tailwind CSS**
   * Menerapkan palet warna kontras tinggi korporat (Wing Blue, Racing Red, Energy Gold) dengan latar belakang komputasi visual *The Latent Substrate* yang diakselerasi GPU.
4. **Keystatic Git-Based CMS**
   * Integrasi sistem manajemen konten lokal tanpa dependensi database eksternal, menyimpan seluruh data proyek dan linimasa sebagai file Markdown/Markdoc terstruktur.
