## Mission Briefing
**Field Service Pro** is a mobile application designed to streamline operations for field technicians in low-connectivity environments.

### Operational Objectives
* **Offline Resilience:** Engineered a bi-directional sync system using SQLite for local storage, ensuring 100% uptime even in dead zones.
* **Security Protocol:** Implemented a secure login system with biometric authentication (Fingerprint/FaceID).
* **State Control:** Utilized the BLoC pattern to manage complex application states and data flows.

### Tech Stack
* **Frontend:** Flutter (Dart)
* **Backend:** Laravel 11 API
* **Database:** MySQL + SQLite
